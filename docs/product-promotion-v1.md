# showly AI 产品宣传平台：第一版产品功能文档

日期：2026-10-23  
状态：第一版骨架已实施（产品档案、活动、内容版本、检查审核、任务、发布记录、指标、导出；录屏视频渲染等媒体制作项除外）

本文描述目标用户、使用流程、首版功能、范围边界与业务验收标准。技术实现参见[代码改造方案](product-promotion-v1-implementation.md)与[实施状态](product-promotion-v1-status.md)。

## 1. 产品定位

Vibe coding 加快了应用开发，但产品上线后仍需要讲清价值、制作演示、发布宣传并吸引真实用户。本平台面向独立开发者和小团队，将产品信息整理、宣传策划、素材制作、审核和发布记录串成一条流程。

**核心价值：提供产品入口，由 AI 理解产品、自动获取截图、操作录制演示，并生成可审核、可发布、可复用的宣传内容。**

第一版的核心交付是一套产品宣传包，包含平台文案、产品截图卡片、公众号文章和录屏演示视频。以准确性、交付质量和操作效率作为首要目标。

## 2. 首版目标与使用假设

- 先服务独立开发者和小团队，支持一个使用者管理多个产品。
- 首版自动采集面向可通过浏览器访问的 Web 产品，支持公开页面，以及用户授权登录后的演示环境；原生桌面和手机应用暂通过上传素材补充。
- 产品截图和录屏不要求用户预先上传。系统根据产品入口与演示目标自动获取真实画面，再生成宣传图和演示成片；上传作为补充或失败时的替代方式。
- 用户拥有产品资料及素材的使用权，负责确认产品事实和最终发布。
- 首版支持人工发布闭环，不要求用户先连接社交账号。
- 核心渠道为小红书、微信公众号，以及适用于短视频渠道的演示视频。
- 媒体服务按需配置；不可用时明确提示，并允许继续完成其他内容。
- 本地单人模式优先验证；若首版直接开放多人服务，认证、数据隔离和执行隔离必须同步完成。

## 3. 核心使用流程

1. 添加产品：提供产品入口，或先填写介绍；需要登录时连接演示账号，截图、录屏和其他资料可选上传。
2. 确认档案：核对 AI 整理的功能、受众、价格和使用限制。
3. 创建活动：选择首次上线、功能更新或场景教程。
4. 确认方案：选择宣传角度、目标渠道和内容清单。
5. 采集与制作：AI 规划关键页面和操作路径，自动截图、操作录屏，再生成文案、卡片、文章和演示成片。
6. 审核修改：检查事实、素材和格式，确认具体内容版本。
7. 导出发布：复制或下载，在官方平台提交后回填链接。
8. 记录效果：录入数据，查看活动表现，形成下一轮建议。

首版验收场景：提供一个可访问的 Web 产品入口，在不上传截图和录屏的情况下，确认产品档案与演示路径，由系统自动获取关键页面截图、执行操作并录制，创建上线活动，生成小红书图文、公众号文章和演示视频，修改审核，导出宣传包，回填发布链接。另以需要登录的演示产品验证授权登录与中断接管。

## 4. 第一版功能

### 4.1 产品管理与产品档案

支持创建、查看、编辑和归档多个产品。产品资料、素材、推广活动和内容分别归属具体产品。

| 输入方式 | 首版范围 |
| --- | --- |
| 产品入口 | 解析公开页面，在授权范围内识别关键功能页，自动截图并规划操作演示；需要登录时由用户连接演示账号 |
| 手动填写 | 产品名称、一句话介绍、受众、功能、入口、定价等 |
| 上传资料（选填） | Logo、文档、已有文案；截图和录屏可用于补充、替换自动采集结果 |

三种输入方式可组合，不要求全部提供。只有产品介绍时仍可生成文字；需要自动截图或录屏时需提供可访问的产品入口。系统围绕演示目标访问相关页面，不无限遍历网站。需要登录时，用户在受控浏览器中完成登录，或连接专用演示账号，授权后继续自动采集。

产品档案包含：

- 名称、官网、产品语言、Logo、品牌色。
- 目标用户、主要痛点和典型使用场景。
- 核心功能及关键操作流程。
- 差异化价值及其依据。
- 当前版本、已上线能力、测试中能力、计划能力。
- 定价、免费范围、试用条件和使用限制。
- 访问、下载或申请体验入口。
- 禁止使用的宣传表述和不能承诺的效果。

AI 提取的信息保存来源与确认状态。未知信息标为待补充，不能推断为产品承诺。首次生成宣传内容前，用户确认基础档案；后续更新保留历史版本。

验收：切换产品不会混用其他产品的素材和功能；未提供定价时不会默认生成“完全免费”。

### 4.2 产品素材库

支持自动采集、上传、预览、命名、分类、说明和删除素材，区分真实采集原件、用户上传文件与加工产物。

**自动获取产品截图：**

- 根据产品介绍和宣传目标识别首页、关键功能、操作过程和结果页面。
- 在选定的桌面或手机视口下访问页面，等待加载和关键内容稳定后截图。
- 支持页面截图、长截图和功能区域截图，自动筛选重复、空白、加载失败的画面。
- 可点击、填写演示数据、切换页面以取得所需状态；用户可修正采集目标并重新获取单张截图。
- 记录来源页面、视口、采集时间、产品版本和操作步骤，自动入库，供卡片和文章引用。

**自动录制产品操作：**

- AI 将演示目标转换为可检查的步骤，例如“输入示例 → 执行处理 → 展示结果”。
- 在指定的演示环境中自动执行步骤并录制真实画面，保存步骤与时间点，供后续剪辑。
- 用户可修改步骤、示例数据、画幅和重点，再单独重录失败片段。
- 遇到登录失效、验证码或不支持的操作时暂停，保留已完成素材，允许用户接管后继续。

首次连接产品时确认可访问页面、可执行操作与演示数据范围，后续在范围内自动执行。使用测试数据或演示账号；付款、删除、对外发送等超出演示范围的操作暂停并请求用户处理。采集时隐藏账号信息、令牌和个人数据，不能确认脱敏的素材不得直接进入已审核内容。

| 类型 | 用途 |
| --- | --- |
| 品牌素材 | Logo、品牌色、固定署名 |
| 产品截图 | 系统自动采集关键功能、操作步骤和实际结果，支持用户补充 |
| 演示录屏 | 系统自动操作并录制真实流程，供剪辑使用，支持用户补充 |
| 证明材料 | 经授权的评价、实测记录、功能文档 |

素材可记录所属产品版本、说明、来源和使用限制。生成任务明确引用所选素材。原始文件不被覆盖；派生图和剪辑视频保存为独立产物。

删除被内容引用的素材时，应提示影响范围并阻止无意破坏已审核内容。

验收：无需上传即可自动获得可用截图与操作录屏。真实产品界面必须来自实际访问和操作，不能用 AI 虚构界面替代；截图排版、标注、装饰及录屏剪辑可以自动生成。

### 4.3 推广活动

一个产品下可以创建多个独立活动。

| 模板 | 用户补充 | 内容方向 |
| --- | --- | --- |
| 首次上线 | 开发原因、核心价值、体验入口 | 产品介绍、开发故事、上手演示 |
| 功能更新 | 改动、新旧区别、适用人群 | 更新说明、流程对比、功能演示 |
| 场景教程 | 用户任务、困难、操作步骤 | 问题切入、教程、实际结果 |

活动配置包括：目标产品版本、目标受众、主要目标、渠道、表达身份、语气、行动引导，以及可选计划日期。

主要目标可选访问、体验注册或收集反馈。表达身份区分开发者本人和产品官方。系统生成活动简报，用户修改确认后进入制作。

验收：不同活动独立保存方案与内容；修改某活动不覆盖其他活动。

### 4.4 宣传策划与任务清单

AI 根据已确认档案提出多个宣传角度，每个角度包含受众、问题切入、核心价值、事实依据、素材、内容形式和行动引导。

用户可选多个角度，也可输入自定义方向。确认后生成内容任务清单，例如一篇笔记、一组五页卡片、一篇文章、一条演示视频。

支持添加、取消和单项重做。方案列出需要自动采集的页面、操作路径与现有素材复用项。先确认角度与清单，再执行采集和媒体制作；自动发现的功能作为待确认事实，不自动升级为宣传承诺。

验收：方案之间具有不同场景或叙述角度，不能只是同一广告文案的同义改写。

### 4.5 小红书图文

- 生成多个标题备选、正文、话题建议和行动引导。
- 生成封面、分页结构和分页文案。
- 自动获取所需产品截图并制作图文卡片，提供手机比例预览。
- 支持编辑文字、替换截图、切换主题色和模板。
- 下载卡片并复制文案。

首版使用固定模板，不提供自由设计画布。字数、图片比例等规则应可配置并随渠道要求维护。

### 4.6 公众号产品介绍

- 生成标题、摘要、完整正文、操作步骤和体验入口。
- 自动采集操作步骤和结果截图，插入对应图注。
- 提供排版预览、富文本复制、HTML 和 Markdown 导出。
- 允许在官方编辑器中继续调整，最终效果以官方预览为准。

### 4.7 产品演示短视频

默认从产品入口自动操作并录制真实流程，再制作演示成片；也可复用已采集录屏或用户上传的录屏。首版优先支持单一场景、单段或少量片段的线性演示。

1. 生成操作步骤、示例数据、解说词与剪辑方案，标明页面、预期结果和预计时长。
2. 用户确认演示目标及范围；系统自动操作产品、录制关键过程，并检查预期结果是否出现。
3. 依据真实步骤时间点裁剪停顿、调整画幅、局部放大和重点标注；失败步骤不能剪辑成成功演示。
4. 添加字幕与可选配音；配音不可用时支持字幕版本。
5. 生成预览及最终 MP4，附带字幕和解说文案。

目标内容可以是 30～60 秒演示，具体时长由素材和方案决定。修改封面、字幕或解说时尽量复用已有中间产物。

首版支持 Web 产品的导航、点击、输入、滚动、文件上传及结果展示等常见流程。复杂画布操作、原生客户端和硬件交互暂不作为自动录制验收范围，也不提供专业视频时间线编辑。自动采集失败需明确原因，允许接管或补充素材，不伪造成功结果。

### 4.8 内容编辑、检查与审核

每条内容独立编辑、预览、保存版本，并支持 AI 局部修改。

| 检查项 | 重点 |
| --- | --- |
| 功能事实 | 不把计划能力写成已上线 |
| 定价与限制 | 不遗漏适用条件，不编造免费承诺 |
| 宣传依据 | 不虚构用户评价和效果数字 |
| 素材一致性 | 画面与功能、版本一致 |
| 平台格式 | 对照已配置规则检查标题、正文和媒体 |
| 内容完整性 | 产品名称、价值和体验方式清楚 |

AI 给出具体问题与修改建议，不替代人工判断。人工确认绑定内容版本；正文、话题或素材变化后，审核失效。产品事实更新后，引用旧事实的内容标为待复核。

支持按要求缩短、改变受众或语气、去除夸张表达，并保留修改历史。

### 4.9 导出、发布与日历记录

- 复制标题、正文和话题。
- 下载卡片、封面、视频和公众号 HTML。
- 按活动导出 ZIP，按渠道分类，附发布说明。
- 打开官方发布入口，由用户自行登录与提交。
- 回填作品链接、实际发布时间和发布状态。
- 保存计划日期，在活动日历查看；计划日期不代表定时任务已建立。

默认采用人工审核与导出流程。导出只标记已导出，不视为已发布；回填的发布记录注明人工确认、未经平台自动核验。

现有自动发布作为可选高级能力保留，按渠道验证后逐步接入新活动模型，不作为首版核心验收依赖。

### 4.10 基础效果记录

执行情况自动汇总：内容数量、待审核、待发布、已发布、作品链接及发布时间。

效果支持：

- 按渠道和内容生成 UTM 链接。
- 手动录入曝光、阅读、互动等指标。
- 通过固定模板文件导入网站访问、注册等汇总数据。
- 按活动、平台和内容对比已获得的指标。
- 基于实际数据生成后续建议，数据不足时明确说明。

每项指标记录来源、统计时间窗和采集时间，区分人工、导入和自动采集。不把曝光、点击、注册混为同一指标，不重复累加不同时间窗的累计数据。

生成 UTM 并不会自动获得访问或注册数据。完整站点事件采集、跨设备归因和付费归因放到后续版本。没有归因证据时不声称某条内容带来具体注册量。

### 4.11 任务与错误恢复

- 展示页面探索、截图、操作录制、策划、生成、渲染和导出等任务状态。
- 支持取消、查看错误、重试失败步骤。
- 单项失败不丢失已完成内容。
- 保存任务输入快照、素材引用、产物和错误摘要。
- 重启后能识别未完成任务，允许恢复或明确重试。
- 发布任务不能因普通生成任务重试而重复提交。

### 4.12 页面结构

| 页面 | 内容 |
| --- | --- |
| 我的产品 | 产品列表、资料完整度、最近活动 |
| 产品概览 | 档案、演示环境连接、素材、版本、活动入口 |
| 推广活动 | 目标、方案、内容清单、任务进度 |
| 内容编辑器 | 编辑、预览、检查、审核、历史版本；查看采集步骤与单项重采 |
| 发布记录 | 导出、计划日期、作品链接 |
| 效果概览 | 执行情况、已有指标、基础对比 |
| 设置 | 模型、媒体服务、账号、默认偏好 |

对话嵌入当前产品和活动，自动带入上下文。技能库放在高级入口，用户无需理解技能名称即可完成任务。

## 5. 首版不包含

- 自动绕过验证码或多因素验证、未经授权的产品操作。
- 原生桌面或手机应用、复杂画布和硬件交互的自动截图与录屏；这些场景支持上传素材补充。
- 全平台无人值守发布。
- 广告投放及预算优化。
- 自动评论、私信营销和自动注册。
- 自由设计画布、专业视频剪辑时间线。
- 完整跨设备、付费及多触点归因。
- 复杂组织权限、订阅计费和团队审批。

## 6. 验证与验收

| 场景 | 预期 |
| --- | --- |
| 多产品切换 | 档案、素材、活动、草稿互不混用 |
| 仅提供可访问的 Web 产品入口 | 无需上传截图和录屏即可完成自动采集并生成宣传包 |
| 页面采集 | 获得清晰、加载完整的关键页面及结果截图，保存来源信息 |
| 操作录制 | 按确认路径执行真实操作，原始录屏与剪辑结果均可查看 |
| 登录或验证码中断 | 暂停并允许用户接管，完成后继续，不绕过验证 |
| 操作或结果失败 | 明确失败步骤，可单项重试，不生成虚假的成功演示 |
| 敏感信息 | 采集素材隐藏个人信息与凭证，未完成处理的素材不能直接通过审核 |
| 缺少价格或效果数据 | 明确缺失，不自动编造 |
| 宣传计划功能 | 检查指出未上线状态 |
| 制作任务失败 | 已完成内容保留，可单项重试 |
| 服务重启 | 已保存内容仍可访问，未完成任务可识别 |
| 审核后编辑 | 旧审核失效 |
| 导出或保存计划时间 | 不标记发布成功，不声称已建立定时提交 |
| 人工回填链接 | 标注人工确认来源 |
| 重复导入指标 | 可识别批次，避免重复累计 |
| 无网站事件数据 | 不虚构注册归因 |
| 未配置语音服务 | 明确降级为字幕视频或提示补配 |

本文描述目标功能，不代表新增能力已在当前仓库落地。
